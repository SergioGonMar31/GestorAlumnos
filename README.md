# GestorAlumnos
Proyecto en Kotlin que gestiona alumnos.
El proyecto incluye las siguientes funciones: 
- Registrar alumnos
- Listar alumnos
- Calcular la media de los alumnos
- Mostrar alumnos aprobados
- Mostar alumnos Suspensos
- Buscar alumnos
- Eliminar alumnos

---

Proyecto realizado como trabajo de clase
